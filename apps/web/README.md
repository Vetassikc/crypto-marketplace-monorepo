# Marketplace Web App

Frontend for Marketplace V2 built with Next.js App Router.

## Local Run
```bash
npm run dev
```

Default local URL: `http://localhost:3000`

## Required Environment
Create `apps/web/.env.local` from `apps/web/.env.example` and configure:
- `NEXT_PUBLIC_API_URL`
- `GOOGLE_GENERATIVE_AI_API_KEY`
- `OPENROUTER_API_KEY`
- `OPENROUTER_MODEL` (optional override)
