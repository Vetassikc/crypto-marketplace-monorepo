# SPRINT_PLAYBOOK

## Weekly Cadence (Solo/Founder Mode)
- Monday: planning (max 3-5 tasks).
- Tue-Thu: implementation + local checks.
- Friday: integration smoke, docs sync, release candidate.

## Sprint Lifecycle
1. Select sprint goal and lock scope.
2. Create/update tasks from template.
3. Implement vertical slices.
4. Run `verify` gate and smoke checks.
5. Update docs, changelog, walkthrough.
6. Prepare release note and push/merge.

## Mandatory Artifacts per Sprint
- `task.md`
- `implementation_plan.md`
- `walkthrough.md`
- `CHANGELOG.md`
- Updated docs in `docs/`

## WIP Limits
- Max 1 active P0 task at a time.
- Max 2 active tasks overall in solo mode.

## Sprint Exit Criteria
- Goal delivered or explicitly de-scoped with reason.
- DoD checklist completed.
- Release note written.
